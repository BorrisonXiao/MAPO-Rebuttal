# MAPO rebuttal drafts

A reading and copying page for the four reviewer responses. The Markdown in
`responses/` is preserved byte for byte. Rendering changes only presentation,
including headings, blockquotes, tables, and mathematical notation.

Live page: https://borrisonxiao.github.io/MAPO-Rebuttal/

The page offers whole-response and per-point Markdown copying, individual source
downloads, a ZIP of all four originals, and light/dark themes. Copy buttons do not
include the page navigation or other interface text. If clipboard access is
unavailable, the original Markdown opens in a selectable text box.

## Overleaf project

Download [the Overleaf ZIP](https://borrisonxiao.github.io/MAPO-Rebuttal/mapo-rebuttal-overleaf.zip)
and select **New Project → Upload Project** in Overleaf. Compile `main.tex` with
pdfLaTeX, then edit the four files in `responses/`, one per reviewer. The ZIP
contains ordinary editable LaTeX, the original Markdown, and a source manifest.
Only formatting and LaTeX escaping are changed during conversion.

`build.py` also regenerates `overleaf/` and the downloadable ZIP using
`build_overleaf.py`. Edits made in Overleaf do not automatically update the
Markdown source or webpage.

## Rebuild

```bash
python -m pip install -r requirements.txt
python build.py
python -m unittest discover -s tests -v
python -m http.server 8000 --directory site
```

Open http://localhost:8000/. To snapshot newer originals before rendering:

```bash
python build.py --source-dir /path/to/responses/claude
```

Commit the changed `responses/` and generated `site/` files, then push `main`.
The workflow rebuilds and checks source preservation on every push to `main`.
Publish the committed output with normal Git authentication:

```bash
python publish.py
```

GitHub Pages serves the root of the `gh-pages` branch. The helper validates the
site and makes a normal, non-forced push to that branch; GitHub then builds and
deploys it automatically. Check the successful **pages build and deployment** run
and the live page before sharing an update. This avoids requiring a separate
GitHub API token. Git's user name and email must be configured for new commits.

## Source preservation and dependencies

`site/source-manifest.json` records each original's SHA-256 digest and byte count.
The tests compare each snapshot with the downloaded file, ZIP member, and embedded
copy payload. The per-point payloads concatenate to the corresponding original
after its introductory paragraph.

MathJax 3.2.2 (Apache-2.0) is bundled in `vendor/mathjax/`, so equations do not
depend on an external CDN. The theme is adapted from the html-report skill's
`htmlkit.py`. No rebuttal wording is generated by the page scripts.
